Michiguardian

Resumen
Michiguardian es una infraestructura de gestión de secretos y bóveda de identidades diseñada bajo el paradigma de "Zero-Knowledge Architecture". Permite a los usuarios centralizar y resguardar credenciales críticas mediante cifrado de grado militar (AES-256) realizado íntegramente en el cliente, asegurando que ni siquiera el servidor tenga acceso a los datos originales.

Arquitectura y Backend
Backend robusto construido con Java 17 y Spring Boot 3.2.3 bajo los principios de Clean Architecture y DDD. Implementación de Spring Security para una protección por capas, junto con Spring Data JPA para la persistencia eficiente en MySQL.

Seguridad Avanzada
• Cifrado AES-256 realizado íntegramente en el cliente, con derivación de claves via PBKDF2.
• Autenticación moderna con JWT (jjwt), Refresh Tokens seguros y hashing de contraseñas con BCrypt.
• Rate Limiting de grado industrial mediante Bucket4j para prevenir ataques de fuerza bruta.
• Autenticación biométrica sin contraseña (passkeys) con WebAuthn4j, incluyendo flujo de vinculación por QR.
• Verificación de contraseñas filtradas (breach-checking) y sanitización dinámica de contenido con JSoup.

Frontend Moderno
• Desarrollado con Next.js 15 y React 19 para una performance excepcional, con soporte PWA.
• Animaciones táctiles y transiciones fluidas con GSAP y Framer Motion.
• Diseño UI resiliente con Radix UI, Tailwind CSS 4 y gestión de estados con TanStack Query.

DevOps e Infraestructura
• Contenerización del ecosistema completo (Java API + Next.js App) mediante Docker y Docker Compose.
